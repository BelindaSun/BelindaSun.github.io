Hello World 2026年8月31日

真的有了 AI 同事和下属

昨天我的朋友圈分享：

Coding agent 最惊人的生产力变化：
过去需要翻译＋编辑＋前端开发＋网站工程维护，现在这些都不需要了；过去需要几个人干几个星期，现在，AI 只用不到半小时；过去花多少钱不知道，现在也就几块钱的事儿。

那是在重置帝 Tibo 在 Codex 用户达到 25m 之际宣布第二天又要重置额度、我没有其它项目可做，于是让 codex 帮我把 learning wiki 网站的英文版做出后的有感而发。

因为我打个盹儿的工夫，Codex 已经做完了：

整个双语改造目标已完成，总计使用 233,226 tokens，历时约 20 分钟。

这，就是生产力的指数级提升。

今天一大早就在推特上刷到了一篇 Uber Engineering 的文章：《Running a Software Factory Efficiently at Uber Scale》，看后颇为震惊，因为 Agent 也已经开始进企业干活了，我虽然知道很多传统企业已经开始用，但没想到有的公司已经走得这么深入了。我就第一时间跟贾皮特分享。

他说：昨天你刚说了"人类未来是要管理目标，让 Agent 去管理 Agent"，今天 Uber 就给你送来了一个工业级 case study。

确实。看一下 Uber 跟我们分享了什么：70%+ 的 PR 已来自 Agent，内部有 3,600+ Agent Skills，每天执行 30,000+ 次；更值得注意的是，越来越多任务已经不需要人来启动——系统发现问题，Agent 自己干，必要时才找人；而且通过各种优化手段（非常值得借鉴），AI 总账单一分没涨，单次会话成本降低了 52%，他们直接把软件工程做成了一座全自动的软件工厂。（比如：他们把 5 分钟缓存改成 1 小时，这个可太厉害了，我现在都不敢让 Claude 或 Codex 闲 5 分钟以上（所以把自己累惨了😂），可惜现在这个只有企业级用户才能改）

我问贾皮特现在企业"agent 化"程度如何，他引用了 McKinsey 和 Deloitte 最新的调查：

McKinsey：40% 的大型企业已经在规模化使用 AI Agent，31% 已规模化使用 Coding Agent，以及 32% 的受访企业因为 coding agents 可以内部开发而放弃购买至少一个软件产品／功能。

Deloitte：真正规模化部署跨职能 Multi-Agent 的目前只有 15%；只有 5% 认为自己的业务流程对 Agent 已高度准备好。

还有 BNY，它在 Q1 报告里就已经披露有约 140 个真正的 Digital Employees。这些已经不是普通 chatbot：它们有自己的登录凭证、头像、企业通讯录员工编号，还有指定的人类 manager 负责分配任务和审核产出。人类老板已经开始同时管理人类员工和 AI 员工了。

我年初想象的与 AI 成为同事的场景真的走进了现实。

而 Meta 的 Project OT 无疑是个好的反面例子，他们原计划部分团队减少最高 60% 员工，减少管理层，找出能够"一个人完成十个人工作"的高杠杆员工，用 AI agent 与 coding tools 放大剩余员工生产率。第一轮约 10% 的裁员进行了。第二轮在实施前一晚被取消。

Learning 就是，组织重构速度不能简单跟随模型能力曲线，理论上成立的事情，现实中实施起来要困难得多，不能步子迈得太大太激进，员工不是零部件，你不能像重构软件那样随意地重构一个组织。任何部署都要以人为本，毕竟我们发展 AI 是为了让它服务于人类，而不是为了取代人类。

现在可以肯定的是，如果放任不管，AI 一定会取代相当一部分人类的工作，但现实中需要多久、政府会不会人为干预、会遭受哪些阻力等等，都不得而知。我们普通人能做的，就是不必过分焦虑（因为焦虑也没有用），但也要足够重视（毕竟 AI 的影响实实在在），把自己用 AI 武装好，把它作为老师来提升自己，把它作为杠杆来放大自己的能力，如此，就好！

尽人事听天命，一直是我的处世之道。

不过我有一个问题，从年初我就在说人类会马上有 AI 同事、AI 下属。如今随着 agent 能力不断发展，它们不仅自己能干活，还越来越擅长排兵布阵、下达任务、验收成果、管理 AI 团队，那未来有些员工会不会有个 AI 老板呢？
